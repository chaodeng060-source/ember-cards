# Ember · 余温

两个人的真心话大冒险抽牌桌。轮流选「真心话」还是「大冒险」，真随机抽一张，谁抽到谁做。
五档升温，从递眼神一路到最后一寸克制；可选对战局，输的人领一道圣旨。

一部手机放中间就能玩，不用服务器，不用登录，什么都不上传。

> 内容尺度：卡库是成人向的，三档以后直白不遮。只给成年人，只给你们俩。

## 怎么玩

1. 打开页面，选 **慢炖局** 或 **对战局**。
2. 轮到谁，谁点「真心话」或「大冒险」，牌翻开，照着做。
3. 做完点 **完成**；不想做点 **跳过**，下一张自动升一档。
4. 每完成两张升一档，一共五档：心动 → 发烫 → 褪色 → 失措 → 缠绵。
5. 第五档完成四张后，慢炖局进入自由局（可以指定档位抽），对战局结算输赢。

**对战局**：两人各 10 点定力。跳过扣 2；对方答真心话答得敷衍，可以「质询」，成立扣 1，每人限两次。先归零的输，或者打到第五档比分。赢家写一道**圣旨**，输家今晚照办，尺度不超过本局到过的最高档。

**安全词**：桌角那颗按钮，按下去牌局立刻停，什么都不问。按钮上的字在「设置」里改成你们自己的词。圣旨大不过安全词。

**变数牌**：混在池里的花活，代选、加时、交换出题、拍照、禁言、倒带……「设置」里可以关掉。

## 自己写牌

### 不碰代码：设置里直接加（推荐）

设置 → 「我们的牌」，一行一张，立刻混进抽牌池：

```
档位 类型 文案
3 大冒险 用嘴解开对方一颗扣子。
5 真心话 今晚最想从哪一步开始？
```

- 档位 1–5，类型认 `真心话` / `大冒险`（或 `truth` / `dare`）。
- 只存在本机浏览器里，不上传。
- **分享牌组**：把这段文本原样发给对方，对方粘贴进同一个框就有一样的牌。

### 动卡库：改默认牌

卡库在 `src/cards/cards.zh.json`（默认 100 张），格式：

```json
{
  "tiers": { "1": "心动", "2": "发烫", "3": "褪色", "4": "失措", "5": "缠绵" },
  "cards": [
    { "no": 101, "tier": 1, "kind": "truth", "text": "第一次想亲对方是什么时候？说具体到那一秒在干什么。" },
    { "no": 111, "tier": 1, "kind": "dare",  "text": "给对方一个持续十秒的吻，只许碰嘴唇，别的都不许动。" }
  ]
}
```

- `no` 全局唯一。习惯上百位是档位，十位 0 = 真心话、1 = 大冒险、2 = 变数。
- `kind` ∈ `truth` / `dare` / `wild`。
- 写牌的一条规矩：**只写对执行者的指令或问题，不预写任何人的反应**。对方怎么反应是对方的。
- 变数牌里只有 `122`（加时：同一人再抽一张）和 `422`（加码：直接升到第五档）有引擎效果，其余靠人执行。

改完 `npm run build` 就是新牌。

## 跑起来

```bash
npm install
npm run dev      # 本地开发
npm run build    # 产物在 dist/，丢到任何静态托管（GitHub Pages 也行）
npm test         # 引擎测试
```

引擎在 `src/engine/game.ts`，是纯函数状态机（`newGame / pick / done / skip / stop / challenge / setDecree / acceptDecree`），不依赖 React，可以直接拿去接别的界面或者接一个 AI 玩家。抽牌走 `crypto.getRandomValues`，不用 `Math.random`。

## 让 AI 上桌（MCP）

`worker/` 里是同一个引擎的 Cloudflare Worker 版：一桌一个 Durable Object，暴露成 MCP 工具
（`new_game / state / pick / done / skip / stop / challenge / set_decree / accept_decree`），
AI 客户端接一条 URL 就能调工具玩。部署和协议细节见 [`worker/README.md`](worker/README.md)。
